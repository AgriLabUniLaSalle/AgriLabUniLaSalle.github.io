# Contraintes

Dans les contraintes, on peut retrouver différents facteurs :

* Limites technologiques

* Connaissances : Les connaissances, on pourra les améliorés tout au long du projet afin de réaliser au mieux le projet en respectant les conditions sur target spray.

* Prix : Nous avons un budget maximal d'environ 1500 €, c'est à nous de trouver les solutions afin d'être dans le budget. Il faut trouver les bons composants au bon prix. (Rapport qualité / prix).

* Le banc de présentation doit être démontable

Performance :

La caméra doit fonctionner avec précision dans des environnements difficiles :

Conditions météorologiques extrêmes (vent, pluie, brouillard).
Présence de poussière ou de saletés sur les capteurs.
Variations de luminosité, notamment en plein soleil ou au crépuscule.
Détection erronée :
Les systèmes peuvent confondre des mauvaises herbes avec des cultures ou manquer de précision à grande vitesse.

Compatibilité :
Intégrer le système sur des équipements agricoles existants peut poser des défis techniques.
