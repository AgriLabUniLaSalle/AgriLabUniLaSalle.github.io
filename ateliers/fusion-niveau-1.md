# Fusion 360, niveau 1

Cette page présente les bases de la modélisation paramétrique avec **Autodesk Fusion** : esquisses, contraintes, opérations 3D et exports.

> **Niveau :** débutant. Les modules d’usinage sont abordés dans le niveau 2.

---



[Inscription pour étudiants](https://www.autodesk.com/education/free-software/featured)

[Inscription pour utilisation personnelle](https://www.autodesk.fr/products/fusion-360/overview?term=1-YEAR&tab=subscription#personal)

## Déroulé de l'atelier

Logiciel paramétrique

* Visualisation/interface
* Sketch :
* Points/segments et contraintes
* Différents type de rectangle/cercles
* Dimensions
* Paramétrique
* Plans et axe
* Opération create
* Extrusion
* Forme primitive
* Révolution
* (sweep/loft)
* Opération modify (chamfer/fillet/...)
* Autres opérations
* historique
* export DXF / STL
* plugin slicer

Les modules usinage sont abordés dans un autre atelier
